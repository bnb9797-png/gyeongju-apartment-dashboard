# 경주 아파트 대시보드

매매·전세·월세 실거래 자료, 가격 추이, 거래금액·전용평당가격 순위, 한국어 생활권 위치도를 제공하는 정적 웹 대시보드입니다.

## 실행

index.html을 브라우저에서 열거나 GitHub Pages로 서비스할 수 있습니다. 거래자료·지도·스타일·스크립트가 한 파일에 포함되어 있습니다.

## 자료 범위

- 국토교통부 경주시 아파트 신고거래, 계약일 2024-10-01 ~ 2026-10-22
- 2026년 10월 자료는 잠정치이며 자동 갱신되지 않습니다.
- 가격지수는 전용면적당 중위가격으로 계산한 자체 지수이며 공식 KB·한국부동산원 지수가 아닙니다.
- 순위는 선택 조건의 신고거래 기준입니다. 기본 면적은 전용 84~85㎡입니다.
- 월세는 보증금 차이를 보정하지 않은 월 임대료 기준입니다.
- 지도는 생활권 중심의 참고용 위치도이며 정확한 단지 좌표·최신 행정경계와 다를 수 있습니다.
- 외부 길찾기와 기관 링크는 인터넷 연결이 필요합니다.

## GitHub Pages 설정

저장소 Settings → Pages → Deploy from a branch에서 main 브랜치와 /(root)를 선택합니다.
