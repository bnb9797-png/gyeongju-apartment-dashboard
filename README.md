# 경주 집값지도

지도로 보는 경주 아파트 실거래·단지사진

사이트: https://bnb9797-png.github.io/gyeongju-apartment-dashboard/

매매·전세·월세 검색, 가격·면적·기간 필터, 관심 단지, 최대 3개 단지 비교, 거래 CSV, 단지사진·위치 등록, 백업 기능을 제공합니다. 큰 집 캐릭터 세움이를 클릭하면 확대됩니다.

## 지도와 사진

- OpenStreetMap 도로지도와 생활권별 실거래 집계를 표시합니다. 도로 타일 표시는 인터넷이 필요하며 오프라인 다운로드하지 않습니다.
- 정확한 단지 좌표가 없는 경우 생활권 중심과 참고 범위로 표시합니다.
- 6개 단지에 대응하는 공식 단지사진·소개 이미지 14장을 포함했습니다. 1·2단지 통합 이미지는 구분하여 표시합니다. 출처는 화면과 photo-sources.json에 있습니다.
- 푸르지오 공식 단지 갤러리, 아이에스동서, 데시앙, 반도건설의 소개자료를 사용합니다. 사진의 권리는 각 원 권리자에게 있습니다.
- 사용자가 등록하는 사진·위치·관심단지는 현재 브라우저에 저장됩니다. 백업 파일로 옮길 수 있습니다.

## 거래자료

국토교통부 경주시 아파트 신고거래 12,421건, 계약일 2024-10-01 ~ 2026-10-22입니다. 해제 신고를 제외한 수집 시점 자료이며 자동 갱신되지 않습니다. 현재 매물 호가나 KB시세가 아닙니다. 자체 중위값·지수는 공식 가격지수가 아닙니다.

출처: [국토교통부 실거래가 공개시스템](https://rt.molit.go.kr/), [매매 API](https://www.data.go.kr/data/15126469/openapi.do), [전월세 API](https://www.data.go.kr/data/15126474/openapi.do)

## 배포

기존 GitHub Pages 설정인 main 브랜치의 루트 디렉터리를 사용합니다. index.html에 지도 라이브러리·거래자료·사진·캐릭터·스타일을 포함했고, analytics.html에서 시장 분석 화면을 제공합니다. API 인증키 및 Sites 배포 설정은 포함하지 않습니다.

검증: 데이터 필터·집계, 사진 단지 매칭, 스크립트 구문, 내장 이미지, 저장소 지연 시 초기 목록 표시, 지도 실패 시 목록 표시, 캐릭터 확대 및 로컬 HTTP 응답을 확인했습니다. 실제 브라우저 시각 검수는 미완료입니다.
